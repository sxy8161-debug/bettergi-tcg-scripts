# [我不是牌神]爱可菲林尼水形幻人

作者：巨鲸也是咸鱼。版本：0.1.11。适用于七圣召唤 PVE。

角色顺序固定为：**爱可菲 → 林尼 → 水形幻人**。

爱可菲铺设冰召唤物，林尼以隐具魔术箭积累隐具余数，战技消耗余数增伤与治疗，水形幻人触发召唤物接力输出。林尼的射箭与元素战技分别选择。每一步按实际骰子、充能、手牌和附着重新判断。

灵光、角斗士和生成料理结合下一次可支付攻击比较收益；接力也会考虑切人后的调和及最好的伙伴转换，避免爱可菲开场后继续消耗资源普攻。后续重投服务存活的林尼接力，林尼大招计入余数与猫猫帽收益。调和优先消耗当前价值较低的牌，起手天赋也参与筹资比较。只执行当前一步，后续按实际资源重新选择。

起手寻找甜点茶话、灵光、角斗士与伙伴支援，并保留归火圣夜巡礼。「最好的伙伴！」和「一掷乾坤」合计最多保留一张，同时出现或重复时保留最左的一张，其余置换以寻找启动组件；不会一并限制卯师傅、西尔弗和迈勒斯等支援的重复张数。

支持装备出牌后再选择角色的确认页，并兼容卯师傅标题被识别为「卵师傅」的误字。白浪拂沙保留多个实际牌面视图，低置信度动态画面仍补读标题。

起手图库覆盖牌表中的16种初始牌，常见动态外观保留多个真实视图；低置信度时仍补读标题。卯师傅、强劲冲浪拍档与魔女M的祝福提供折叠和展开牌面识别。支援区按固定槽位的边框和完整角标识别占用，满四格时不继续新增支援；意外进入支援弃置页会明确停止，不擅自替换已有支援。

召唤物次数使用完整角标区域，兼容普通牌桌与选择页图样；可见召唤物的身份或次数缺读时保留未知状态。生成料理的相似图块只认到家族，再读实际标题区分牌名；空手牌检查区分敌方支援数字角标与详情标题。

## 启动

使用 BetterGI 0.66.0 或更新版本及简体中文界面，支持 1920×1080、2560×1440、2560×1600 游戏客户区。需较高画质，已知渲染精度至少 0.8，建议 1.0 或更高。开局前设置分辨率，整局保持不变。

复制下方分享码组牌，核对角色顺序；在起手换牌、首次选人或首次掷骰阶段手动启动脚本。行动阶段入口只允许新开局未行动并在设置中确认。
